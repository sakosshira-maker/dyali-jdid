# نشر «Mon petit cahier» على Netlify

## الجديد: لا قاعدة بيانات ولا إعدادات
كل البيانات (استعمال الزمن، المواد، الدفاتر، الملاحظات الصوتية، المزاج، الأوسمة…) تُحفظ **داخل المتصفح نفسه** (IndexedDB، مع localStorage كبديل تلقائي).
لا تحتاجين إلى Supabase أو Neon أو أي خدمة خارجية، ولا إلى متغير `DATABASE_URL`.

## خطوات النشر
1. ارفعي المشروع إلى GitHub.
2. في Netlify: **Add new site → Import an existing project** واختاري المستودع.
3. اتركي الإعدادات كما هي (يقرأها Netlify من `netlify.toml`):
   - Build command: `npm run build`
   - Publish directory: `.next`
4. اضغطي **Deploy** — هذا كل شيء.

## اختياري
- `OPENAI_API_KEY`: لتفعيل إجابات الأستاذ الافتراضي بالذكاء الاصطناعي والاستماع الذكي للإلقاء. بدونه يعمل كل شيء بالمراجع المحلية.

## مهم: البيانات مرتبطة بالمتصفح
- كل متصفح/جهاز له نسخته الخاصة من الدفتر.
- استعملي زر 🛡️ **Mes données** في أعلى الصفحة الرئيسية لـ:
  - **Télécharger ma sauvegarde**: تنزيل نسخة احتياطية كاملة (ملف JSON).
  - **Restaurer une sauvegarde**: استرجاعها على جهاز أو متصفح آخر.
- احتفظي بنسخة احتياطية من حين لآخر، خاصة قبل مسح بيانات المتصفح.
